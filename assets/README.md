# assets/

Медиа и файлы, которые бот отправляет пользователям. Папка хранится в git (в `.gitignore` её нет).

- `logo.png` — логотип в шапке Excel-отчёта: квадрат 260×260, скруглённые углы прозрачные (`config.LOGO_PATH`). В Excel вставляется квадратом 90×90 px.
- `logo_original.png` — прежний круглый логотип (2508×2508), в боте не используется.
- `materials/*.pdf` — «📚 Полезные материалы»; список и подписи — `bot/texts.py` → `MATERIALS`.

Видео и PDF кешируются в Telegram по отдельности (`data/media_cache.json`; ключ — имя файла без
расширения, у материалов — `material:{файл}`).

## how_to_download.mp4

Видео-подсказка «как скачать выгрузку „Топ поисковых кластеров“ из кабинета WB».
Путь задан в `config.py` → `HOW_TO_VIDEO`.

Где показывается:
- шаг «➕ Новый анализ → пришли файл»: видео с подписью;
- «📖 Инструкция» и `/help`: видео с короткой подписью, затем текст инструкции отдельным сообщением.

**Формат:** MP4, видео H.264, **без звука** (тогда Telegram показывает его как GIF-анимацию
и крутит по кругу). Подойдёт и GIF, но имя файла и путь в `HOW_TO_VIDEO` тогда нужно поменять.

**Размер:** до 10 МБ. Лучше 1–3 МБ: быстрее грузится у пользователя. Ширина 720–1080 px,
10–40 секунд.

Пережать запись экрана под эти требования:

```bash
ffmpeg -i запись.mov -an -c:v libx264 -pix_fmt yuv420p -vf "scale=1080:-2" -crf 28 -movflags +faststart how_to_download.mp4
```

(`-an` убирает звук, `yuv420p` нужен, чтобы видео играло в Telegram на всех устройствах.)

## how_to_price.mp4

Подсказка «где смотреть цену реализации»: «Товары и цены» → «Цены и скидки» → колонка
«Цена со скидкой». Путь задан в `config.py` → `HOW_TO_PRICE_VIDEO`.

Где показывается:
- шаг «➕ Новый анализ → цена» (и тот же шаг при «🔁 Пересчитать»): видео с подписью;
- «📖 Инструкция» и `/help`: второе видео, после how_to_download.

**Формат и размер:** как у how_to_download.mp4 — MP4 H.264 без звука, до 10 МБ
(лучше 1–3 МБ). На записи кабинета размывайте данные клиента.

### Как обновить

Просто замените файл. Бот кеширует `file_id` загруженного видео в `data/media_cache.json`.
При смене размера или даты изменения файла кеш сбрасывается, и видео загружается в Telegram
заново. Перезапуск бота не нужен.

Если файла нет или Telegram не принял видео, бот отправляет только текст подписи и пишет
warning в лог. Сценарий при этом не ломается.
